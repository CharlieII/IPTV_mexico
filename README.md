## Sobre el proyecto

Este repositorio contiene una lista **M3U** curada manualmente con canales de televisión pública y abierta de México y países de habla hispana. El objetivo es facilitar el acceso a contenido cultural, informativo y de entretenimiento que ya se encuentra disponible de manera gratuita en internet.

La lista está pensada para toda la familia: **no incluye canales para adultos**. Su contenido se enfoca en cultura, entretenimiento general, deportes, películas y series.

> **Nota:** este proyecto **no** aloja ningún contenido de video. Solo recopila enlaces públicos proporcionados por las propias emisoras oficiales.

## Cómo usar la lista

Puedes utilizar esta lista en cualquier reproductor compatible con el formato **.m3u** o **.m3u8**, como VLC, TiviMate, IPTV Smarters, OTT Navigator, Kodi y otros.

### Enlace directo (recomendado)

Copia y pega la siguiente URL en tu reproductor para recibir actualizaciones automáticas:

```url
https://raw.githubusercontent.com/CharlieII/IPTV_mexico/refs/heads/main/lista.m3u
```

> [!TIP]
> Usa la URL directa para que tu reproductor consulte siempre la versión más reciente de la lista.

### Enlace corto (opcional)

En algunas aplicaciones de IPTV también puedes usar la URL acortada:

```url
https://t.ly/v6HJ6
```

### Pasos generales

1. Abre tu reproductor compatible con listas M3U.
2. Busca la opción para agregar una lista de reproducción o una URL M3U.
3. Pega el enlace directo —o el enlace corto si tu aplicación lo acepta—.
4. Guarda la lista y actualiza el contenido.
5. Selecciona un canal para comenzar a verlo.

## Aviso legal y derechos de autor

> [!WARNING]
> **Este proyecto respeta estrictamente los derechos de autor.**

- Todos los enlaces incluidos en esta lista provienen de **fuentes oficiales** y públicas: sitios web de las televisoras, emisiones oficiales en YouTube, etc.
- No se incluyen canales de pago, señales premium ni contenido pirateado.
- Esta lista es puramente informativa y educativa, y busca facilitar el acceso a la televisión abierta.

Si eres propietario de alguna señal y deseas que sea retirada de esta lista, por favor abre un [Issue](https://github.com/CharlieII/IPTV_mexico/issues) y será eliminada inmediatamente.
